# Expense Tracker

A lightweight, responsive web application for managing and tracking personal expenses effortlessly in your browser.

## Features

- **Add Expenses**: Record expense name, amount in INR (₹), and category.
- **Categorization**: Group expenses into categories: *Food*, *Travel*, *Shopping*, *Bills*, and *Other*.
- **Category Filter**: Filter expenses by a specific category or view all at once.
- **Live Total**: Automatically calculates and updates your total spending in real-time.
- **Persistent Storage**: Saves data to your browser's `localStorage`, keeping your records intact even after closing or refreshing the tab.
- **Responsive UI**: Clean, mobile-friendly design that works on screens of all sizes.

## Tech Stack

- **HTML5**: Semantic markup for forms and layouts.
- **CSS3**: Custom card styling, modern inputs, and responsive media queries.
- **JavaScript (ES6+)**: Dynamic DOM manipulation, category filtering, and `localStorage` state persistence.

## Getting Started

No build tools or external dependencies are required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/khajithSai13/expense-tracker.git
   cd expense-tracker
   ```

2. **Run the project:**
   Simply double-click `index.html` or open it in any modern web browser:
   - On Windows: Right-click `index.html` -> **Open with** -> Your preferred browser.
